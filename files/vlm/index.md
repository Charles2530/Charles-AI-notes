# 视觉语言模型

视觉语言模型把图像或视频中的证据接入语言任务。回答“红杯左边是什么”需要识别对象、保留空间关系、解析问题，再生成对应答案。模型的语言流畅度只覆盖最后一步，不能代替前面的视觉证据。

一种常见生成式结构是图像编码器、连接器、语言模型。图像编码器产生局部特征，连接器改变特征宽度或压缩数量，语言模型在这些特征和问题条件下生成答案。CLIP 这类双编码器则用图文相似度支持检索和分类，并不直接逐词生成回答。理解这一区别，才能把训练目标与输出能力对应起来。

## 沿一张图追踪张量

教学示例中，一张 \(224\times224\) 图像划为 \(16\times16\) patch，得到 196 个位置。视觉编码器若输出 \(196\times768\) 特征，投影到语言模型的 4096 维后得到 \(196\times4096\)。宽度改变了，位置数量仍是 196。如果再用 32 个查询压缩，才得到 \(32\times4096\)。这两种连接器对信息与计算的影响不同。

问题中有“左边”时，模型需要保留空间位置；问题换成“杯身小字写了什么”，则需要足够分辨率与局部纹理。没有一种固定压缩比例能凭结构保证所有任务的证据都保留。

把这条张量链放回杯子场景，视觉编码器先决定哪些外观和位置证据可用，连接器决定语言模型能读取多少证据，回答生成再把它组织成文字。“红杯在左边”回答正确，还不足以给机器人一个抓取目标，因为左边属于哪个坐标系、杯子有多远、观察是否过期都没有确定。视频记忆与动作接口分别补上时间和执行含义，下面的文章按这些实际缺口展开。

## VLM、VLA 与世界模型的分界

VLM 可以根据图像回答“杯子在桌上”。[VLA](../vla/index.md)还需要生成具有单位、坐标与执行周期的动作。世界模型进一步估计这些动作的后果。三者可能共享编码器甚至参数，但目标分别是回答、行动与预测，评测也必须分别建立。

如果一篇模型论文只报告静态问答提升，能支持的结论止于该评测条件下的问答能力。要用于机器人，还要检查几何、时延、闭环状态分布和恢复；要用于规划，还要检查候选动作的预测后果与真实环境是否一致。

## 一条循序渐进的 VLM 学习路径

不要一开始比较几十个模型名。先用同一张图完成四次输入干预：

1. 原图 + 问题，检查模型是否能回答可见事实。
2. 原图裁剪掉目标，检查答案是否仍然凭语言先验猜测。
3. 保留目标但交换左右位置，检查空间证据是否真正进入表示。
4. 降低局部文字分辨率，检查 OCR/小目标能力的阈值。

每次只改变一个视觉因素，并保存图像版本、问题、答案、置信度或评测结果。这样“模型看到了”不再只是主观判断，而是一个可以被图像反事实推翻的假设。

## 训练目标和能力要一一对应

| 训练/对齐目标 | 主要学到什么 | 不能直接推出 |
| --- | --- | --- |
| 图文对比学习 | 图像和文本的全局相似性 | 精确生成每个 token 的答案 |
| 图像条件语言建模 | 根据视觉条件生成文字 | 空间坐标、精确计数和事实可靠性 |
| 指令微调 | 按任务格式回答、解释或拒答 | 视觉证据真的被使用 |
| 区域/定位监督 | 对象与位置对应 | 复杂指令下的闭环动作 |
| 视频/时序目标 | 表示变化、记忆或预测 | 真实世界中的控制后果 |

训练页面应明确哪些 token 被 mask、图像特征在哪一层注入、梯度是否回到视觉 encoder，以及连接器是否改变 token 数。一个“多模态模型”标签不说明这些细节。

## 用 token 预算理解分辨率和成本

若图像被切成 patch，粗略 token 数为

\[
N_{\text{patch}}=\left\lceil\frac{H}{P}\right\rceil
\left\lceil\frac{W}{P}\right\rceil.
\]

提高分辨率会增加视觉 token 和语言模型上下文成本；压缩器减少 token 可能保留全局语义，却丢失小字或空间细节。多图和视频还会乘上帧数或视角数。报告 VLM 的上下文长度时，要分别说明文本 token、视觉 token、压缩后的 token 和是否存在跨帧记忆。

## 评测不能只用 VQA 平均准确率

建议把评测拆成五组：

| 评测组 | 例子 | 主要失败信号 |
| --- | --- | --- |
| 事实识别 | 图中物体、属性、计数 | 幻觉、漏检 |
| 空间关系 | 左右、前后、相对位置 | 语言先验、坐标混淆 |
| 细节读取 | 小字、表格、图例 | 分辨率与裁剪不足 |
| 反事实 | 交换/遮挡/替换目标 | 没有使用视觉证据 |
| 校准与拒答 | 无法确定或图像缺失 | 过度自信 |

若用于机器人，再加上观测年龄、坐标误差、动作条件和闭环成功率。静态 VQA 的提升只能支持静态任务范围内的结论。

## 从 VLM 过渡到 VLA 前的检查点

在进入 [VLA](../vla/index.md) 之前，至少能回答：

- 当前视觉特征对应哪个时间戳，是否与机器人 state 对齐？
- 图像中的“左”如何映射到相机、世界或机器人坐标？
- 连接器压缩后，哪些局部证据还可用？
- 模型输出是文本、离散 action token 还是有单位的连续动作？
- 视觉回答错误时，系统如何拒答、重观测或停止动作？

这些问题把“看懂图”与“能执行动作”分开，也解释为什么 VLM 的 benchmark 分数不能直接替代 VLA 的闭环实验。

## 自测

1. (224\times224) 图像用 (16\times16) patch 时有多少 patch token？如果 connector 压到 32 个 token，语言模型看到的宽度和位置数分别怎样变化？
2. 交换图像左右位置后答案不变，说明需要优先怀疑视觉 encoder、connector、语言先验还是评测问题？
3. 为什么提高分辨率可能改善小字识别，却同时增加推理成本？
4. 设计一个从 VLM 静态问答过渡到 VLA 动作接口的最小实验，并列出时间戳、坐标和安全停止条件。
