# 动态系统、反馈控制与规划

一个物体离目标还有2个单位。每一步可以向左或向右移动1个单位，动作会改变下一状态。控制要选择动作，让状态逐步接近目标；如果真实运动和预测不同，还需要用新观测修正计划。

先用 \(s_{t+1}=s_t+a_t\) 算完两步规划，再讨论稳定性、连续动力学和状态是否可观测。这里的模型与成本都是演算设定。

## 状态必须足够预测下一步

在这个简化模型中，位置s加动作a足以决定下一位置。若真实系统还具有惯性，只记录位置就不够，同一位置、不同速度会产生不同未来，需要把状态扩成 \(x=(s,v)\)。

一般离散模型写为 \(x_{t+1}=f(x_t,u_t)\)，有噪声时改成条件分布。观测 \(y_t\) 则由传感器产生，未必包含全部状态。学习到的latent是否保留速度、接触和遮挡信息，需要通过后续预测或控制检查，名字叫state并不能保证充分。

## 两步候选怎样比较

从s0=2出发，动作只能取-1或+1，目标为0，成本定义为

\[
J=s_1^2+s_2^2+0.1(a_0^2+a_1^2).
\]

位置平方惩罚离目标远，动作平方惩罚控制强度。

| 动作序列 | 预测位置 | 成本 |
| --- | --- | ---: |
| (-1,-1) | 2→1→0 | 1.2 |
| (-1,+1) | 2→1→2 | 5.2 |
| (+1,-1) | 2→3→2 | 13.2 |
| (+1,+1) | 2→3→4 | 25.2 |

最优候选是(-1,-1)。MPC通常只执行第一步，再获取观测。如果真实新位置是1.2，下一次从1.2重新规划，而不是继续假定自己位于1。反馈的作用在于持续修正模型与现实的差异，仍不能消除全部延迟、观测误差或模型错误。

```python
from itertools import product
for actions in product([-1,1],repeat=2):
    state,cost = 2.,0.
    for action in actions:
        state += action
        cost += state*state + .1*action*action
    print(actions,round(cost,1))
```

## 稳定性回答扰动会怎样演化

对离散线性系统 \(x_{t+1}=Ax_t\)，所有特征值模严格小于1时，零点渐近稳定。边界模等于1还需检查Jordan结构。连续系统 \(\dot x=Ax\) 的对应判据是特征值实部严格为负，不能把两个条件互换。

标量系统每步把误差乘1.2，初始0.1在10步后约0.6192；乘0.8则降到约0.01074。若每步还有固定偏差0.02，\(e_{t+1}=0.8e_t+0.02\) 的长期误差为0.1，稳定不代表无偏。

反馈能改变动力学。对 \(x_{t+1}=1.2x_t+u_t\)，取 \(u_t=-0.5x_t\)，闭环系数变为0.7。若执行器饱和或动作延迟一拍，实际方程已经改变，不能继续套0.7的结论。

## 连续向量场与离散控制之间

连续模型 \(\dot x=f(x,u,t)\) 给出当前状态的瞬时速度。用步长h离散化，最简单Euler更新是 \(x_{k+1}=x_k+h f(x_k,u_k,t_k)\)。步长由控制频率决定，也影响数值误差与响应延迟。

生成模型也会求解向量场，但其“时间”可能是噪声插值坐标，不是机器人真实秒数。变量含义与单位相同之前，不能直接比较它们的步长或速度。

## 连续动作太多时怎样搜索

CEM可在动作序列空间维护一个分布，每轮采样候选，用模型计算成本，选择成本最低的elite，再用elite均值和方差更新搜索分布。

令一维代价 \(J(a)=(a+1)^2\)，本轮候选(-2,-1,0,2)对应成本(1,0,1,9)。选择两个elite，并在同分时保留先出现的候选，得到(-1,-2)，新均值-1.5、方差0.25。下一轮围绕这个区域继续搜索。

它无需对成本求导，却需要许多rollout。方差过早缩小可能遗漏其他好区域；可行域非凸时，两个可行动作的均值也未必可行。CEM得到的候选应继续检查约束，不能把一次采样结果视为全局最优。

## 能控制与能看见是两件事

对 \(x_{t+1}=Ax_t+Bu_t,y_t=Cx_t\)，n维线性状态的可控矩阵和可观测矩阵分别为

\[
\mathcal C=[B,AB,\dots,A^{n-1}B],\qquad
\mathcal O=[C^\top,(CA)^\top,\dots,(CA^{n-1})^\top]^\top.
\]

满秩分别表示状态方向能通过有限步输入影响，以及初始状态能通过输出序列区分。取位置速度模型 \(A=[[1,1],[0,1]],B=(0,1)^\top,C=(1,0)\)，得到 \(\mathcal C=[[0,1],[1,1]]\)、\(\mathcal O=[[1,0],[1,1]]\)，均满秩。

输入只直接改速度，却能通过后续移动影响位置；传感器只测位置，却能用连续位置差反推速度。这些结论针对理想线性模型。噪声、幅度约束、有限时间和安全区域仍会限制实际控制。
