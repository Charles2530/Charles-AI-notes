方案 B：新的学习架构

原则：先用 4 篇文章形成完整闭环，再按理论、控制、加速和应用分叉。

专题入口
扩散模型专题首页（重写 index.md，并加入导航）

首页只做三件事：一句话定义扩散模型；展示训练/采样完整闭环；给出基础主线和进阶地图。

第一层 · 必修基础主线
1 · 新增
从零理解扩散模型

生成模型问题、加噪/去噪直觉、训练与生成为何不同、能做什么与不能做什么。

2 · 重写旧文
DDPM 数学与训练

前向闭式采样、反向过程、噪声预测损失、训练/采样伪代码；现有 training.md 承担此职责。

3 · 新增
网络与 Stable Diffusion

U-Net / DiT、时间嵌入、VAE、文本编码器、cross-attention、scheduler 的完整数据流。

4 · 新增
最小 PyTorch 实现

在小数据集上实现加噪、模型、loss、采样与可视化；把公式逐行映射到代码。

第二层 · 进阶分支
A · 理论坐标系

发展脉络 → 噪声日程与参数化 → Score Matching / SDE → Flow Matching / Rectified Flow（新增独立页）

B · 条件与采样

Guidance 与条件控制 → DDPM / DDIM / Solver → 方法选择对照

C · 少步与部署

蒸馏 → Consistency / LCM（从原来的 Flow 合并页中拆出）→ 训练配方与故障分析

D · 应用扩展

视频与多模态扩散 → 站内论文精读：Score SDE、DPM-Solver++、DMD、Wan 等
