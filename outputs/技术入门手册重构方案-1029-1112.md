# 技术入门手册重构方案

本方案按用户最新要求修订。目标是提供完备、可自选阅读的 AI 技术入门，论文精读帮助读者理解原文并实现核心方法。前版的十阶段课程、课次和阶段验收安排不再作为实施依据。

## 网站应当提供怎样的阅读体验

读者可以带着一个技术问题进入，例如 attention 怎样计算、模型为什么要微调、KV cache 保存什么，或世界模型如何影响动作选择。文章先把当前问题解释完整，再给出必要的前置补充和深入方向。读者不必完成一条统一路线，也不需要靠课次判断自己的位置。

第一次接触某个方向的人可以读专题总览，先知道有哪些对象、它们怎样配合、常见方法分别处理什么困难。已经读过相关内容的人可以直接查具体机制。准备读论文的人可以从方法页继续进入对应原文和精读。

正文应持续回答读者自然产生的问题。公式、图示和代码出现在需要它们的位置。首页不设置课程进度、打卡、阶段任务或考试式验收。

## 完备的含义

完备性由解释所需的知识是否齐全来判断。对一个重要技术，读者应该知道它处理什么问题，操作什么数据，内部怎样计算，依赖哪些假设，与相近方法有什么差别，在哪些条件下值得使用，以及怎样核对实现。

篇幅按问题复杂度决定。概念简单时几段足够，涉及概率目标、梯度估计或训练流程时就展开必要推导。正文中出现尚未建立的关键知识时，提供当前段落够用的说明和准确链接。大量名词、方法清单或长参考文献列表不能代替这些解释。

覆盖范围以当前网站的 AI 技术栈为中心，包含数学与计算、机器学习基础、神经网络结构、训练、推理与效率、生成、决策、多模态、世界模型与具身应用。传统机器学习中直接支撑这些内容的回归、分类、数据划分、偏差与方差等概念需要讲清；暂不把所有传统算法扩成同等篇幅的百科。

## 知识怎样组织

建议使用下面八个主要专题。首页用简短的问题说明与依赖关系帮助定位，侧栏只展开当前专题。

| 专题 | 核心内容 | 需要补好的连接 |
| --- | --- | --- |
| 基础知识 | 任务、样本、特征、概率与统计、必要数学、张量、计算图、梯度和评测 | 从数据与预测出发，把数学接到真实计算 |
| 模型结构 | 线性层、MLP、卷积、表示学习、attention、Transformer、位置、归一化、MoE、SSM | 从基本运算解释模块组合，再讨论架构改动 |
| 训练 | 数据、损失、优化、预训练、微调、蒸馏、偏好优化、分布式执行和稳定性 | 分开方法改变与系统执行，说明哪些量被更新 |
| 推理与效率 | 解码、KV cache、服务调度、RAG 与工具调用、量化、算子、编译和测量 | 先解释推理过程，再说明优化发生在哪里 |
| 生成模型 | 生成目标、潜变量、VAE、扩散、score、flow、采样、条件控制、蒸馏和视频 | 连接概率目标、训练信号与采样过程 |
| 强化学习 | 交互、MDP、价值、策略梯度、actor-critic、离线学习、模型驱动决策和应用 | 说明数据来自哪里、目标怎样估计、策略如何改变 |
| 多模态与具身 | 视觉表示、VLM、空间与坐标、动作表示、VLA、世界模型、规划、控制与评测 | 区分感知、预测、决策和执行各自承担的工作 |
| 论文精读 | 按领域与技术问题组织的论文解析、相关方法关系和实现说明 | 从通用机制回到论文的具体改变与证据 |

数学仍保留完整专题索引，进入基础知识中的数学工具部分。读 attention 时只需补相关矩阵运算和概率归一化；读扩散时再连接条件分布、潜变量和连续时间方法。读者也可以主动系统查数学，但首页不要求所有人先读完数学。

工具、术语表和 QA 放在辅助入口。探索文章明确标识为分析或假设，避免与已建立的机制说明混读。原文 URL 尽量保留，分类与导航调整通过配置和互链完成。

## 每一篇文章怎样变得适合入门

以下是编辑判断，不要求每篇使用完全相同的六个标题。

### 先建立一个足够具体的问题

介绍 attention 时，先说明如何让当前位置利用其他位置的信息。介绍量化时，先给一个连续数值如何映射到有限格点的例子。介绍世界模型时，先说明已知观测和候选动作时，需要预测什么量。

读者先认识对象与需求，再理解形式定义。工程代价在机制成立后解释，避免一开始就同时要求理解吞吐、调度、缓存和部署约束。

### 给出能跟着走完的过程

一篇 attention 入门应至少让读者看完一次从输入向量、Q/K/V、分数、归一化到输出的计算。张量形状和 softmax 的轴放在对应步骤说明。掩码通过同一个例子解释，读者能观察屏蔽一个位置以后输出怎样变化。

代码片段只在能帮助理解具体运算时出现。代码太长时提供完整文件，正文解释关键行和输出。数值例子是讲解的一部分，不转成强制作业。

### 公式解释要再往前走一步

说明符号以后，还应解释公式为何这样写，以及改变某一项会带来什么变化。涉及优化时，区分目标值、梯度、参数更新和约束。涉及概率时，区分训练中能够观测的量与推理时只能预测的量。

推导有助于理解时保留关键中间步骤。需要额外假设的等价变形说明假设，无法核实的论文推导回到原文核对。通用数学的教学例子可以自行构造，但应标明其用途，不能写成论文实验结果。

### 让初次阅读有清楚的结束位置

当前 Transformer 基础页同时讨论 tokenization、Q/K/V、不同注意力接口、KV cache、FlashAttention 和 MoE。修订时把 attention 的计算说明完整，接着简短说明它在 Transformer 中的位置。缓存、内存优化和稀疏专家由各自文章展开。

同样，训练入门集中说明数据如何形成损失、梯度如何更新参数、训练与验证为何不同。分布式切分、集群管理和规模规律进入后续专题。深度内容继续保留，但文章的主问题要清楚。

### 比较必须建立在同一个问题上

比较 GPTQ、AWQ 与 SmoothQuant 时，先解释量化对象、误差与校准，再比较它们分别改变了哪个环节。比较 DDPM、DDIM 与 Flow Matching 时，分开训练目标、概率路径和采样求解。介绍 VLM、VLA 与世界模型时，明确各自输入、输出与下游用途。

方法数量按解释需要决定。比较表负责压缩已有论证，不能替正文首次引入一长串未解释名词。

### 边界跟着具体机制出现

说明什么时候成立、可能在哪个环节失败，以及如何观察这种失败。避免每页末尾重复一套部署清单或宽泛风险。对新手，最有价值的是能把异常与机制对应起来，例如掩码错位、目标错位、张量轴混淆或评测泄漏。

## 专题之间怎样连接

每个知识点确定一篇主要解释文章。其他文章给出本段所需的简短回顾，并链接到那篇主文，减少多个页面反复定义同一术语。

链接标明关系。前置知识说明缺少它会卡在哪里；相关机制说明两者如何配合；深入阅读说明新文章增加了什么；论文实例说明该论文具体使用或改变了什么。

例如读 KV cache 的人，应能直接补到 causal attention 与自回归生成。读 PagedAttention 的人，再进入动态 KV 管理与服务调度。读者无需在数学、基础、推理、QA 和论文五处猜测哪个链接最适合当前问题。

跨专题内容按主要问题归属。RLHF 的偏好数据与训练流程放在训练中，策略目标和估计方法回链强化学习。Transformer 的注意力计算放在模型结构中，FlashAttention 的内存访问实现放在推理与效率中。这样既支持跨领域阅读，也减少重复解释。

## 论文精读如何深化

PaperPilot 的深读和方法提示词适合成为编辑标准。正文从具体困难进入总体方法，沿输入到输出讲清信息流，再展开决定性公式和实验。原文事实、作者解释、第三方观察与教学分析保持来源区分。

每篇论文优先讲透三个问题。

1. 相比已有做法，这项工作具体增加、替换或删除了什么，其必要性是什么。
2. 新机制怎样作用于表示、概率分布、优化过程或系统执行，哪些公式表达了这种改变。
3. 论文中的哪些实验支持这些解释，比较条件是否一致，尚有哪些替代解释。

对实现有帮助的信息包括张量接口、训练与推理步骤、冻结和更新的参数、梯度处理、数据预处理与必要超参数。材料不足时说明具体缺口。完整工程实现、缩小的核心方法实现和仅验证执行的示例分别标识，避免把随机数据跑通称为复现。

论文目录先展示领域和技术问题。经典方法、后续改进和当前路线的关系可以辅助选择；日期用于查找，不承担学习顺序。进入某篇论文时，先给少量与核心机制直接相关的基础链接。PDF 阅读器放到工具入口，并提供返回已有精读的链接。

## 如何处理现有内容

保留已经讲清的部分，例如 Transformer 的 shape 说明、RSSM 的 prior 与 posterior 区别、DDPM 的公式代码对应。扩写时补缺失的推理步骤或例子，压缩时删除重复的背景、判断和不必要的关联方法。

先按页面的主要作用整理现有材料，再决定合并、拆分或补写。概念说明、算法机制、系统实现、论文解析和探索意见各有写法。拆页只有在主问题确实不同、读者能独立理解新页时才做，避免把连续论证切成碎片。

完整的技术入门会涉及现有正文的实质修订。新增首页与索引只解决定位问题，不能替代内容改造。对每个专题记录哪些文章已评估、哪些已修订、哪些仍待查证，不给未处理内容套上统一的完成标记。

## 首轮具体修改范围

先处理全站组织和最常用的基础文章，形成可检验的样板。

- 新建技术地图首页，重排主要入口，恢复论文总览，整理目前未进入导航的 VLM 页面。
- 修订张量与 shape、线性层、梯度与训练、attention、生成与解码等基础内容，补齐必要算例并清楚划分文章范围。
- 整理训练、推理、生成、强化学习和多模态具身的专题总览，说明核心对象、方法分类及与其他专题的关系。
- 选择有足够材料的论文解析，补齐基础连接、关键公式、训练推理及实验解释，形成后续逐篇修订的参照。
- 修订过度依赖标题和固定措辞的检查，同时保留导航、链接、资源、数学渲染、元数据和运行行为检查。

之后按专题逐批深化正文，每批检查解释是否完整、链接是否合理、代码是否可运行和事实是否有来源。全站事实重验涉及回到论文和官方材料，不能仅凭已有笔记相互引用完成。

## 怎样判断重构有效

技术入门页应当让首次接触的读者看清对象、计算和用途。原文中的关键跳跃能在本站找到解释，代码中的主要变量能够对应回正文，相关文章能沿明确关系找到。检查的是文章是否提供这些条件，不以阅读进度或完成作业作为标准。

工程上继续执行严格构建、链接与资源检查、相关测试和桌面及窄屏阅读检查。已有基线为构建通过，测试 164 项通过、27 项失败、12 项跳过；后续逐项区分原有失败和新增回归。内容审核按具体公式、数值、来源和比较条件记录。

分支继续只有 `main`。不创建新分支或 worktree，原有工作目录和历史备份保持可恢复。网站代码与内容尚未按前版课程方案修改。
