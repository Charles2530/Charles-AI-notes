## 哪些地方具体阻碍学习

### 入口让新读者过早承担选择任务

在本地构建的浏览器页面中，根地址跳转到数学目录。首屏要求系统学习者按五组内容顺读，第二篇就进入谱分解、Newton-Schulz、Hessian 和 Fisher，之后才是微积分。这个顺序适合作为主题索引，难以直接承担入门课程。

[数学总览](../files/prerequisite-math/index.md) 与 [导航配置](../mkdocs.yml) 可直接核对这一点。应增加独立首页，给出一条默认起步路线，并把数学按当前任务引入。二阶方法、ODE/SDE、控制与三维几何分别放到需要它们的阶段。

### 一篇基础课承载了过多后续主题

[Transformer 基础页](../files/foundations/transformer-attention-and-tokenization.md) 依次涉及 tokenizer、Q/K/V、多模态拼接、KV cache、FlashAttention、MoE 与现代架构。各段有价值，但初学者尚未完成一次 attention 的计算，就要处理多个系统和研究问题。

[线性代数页](../files/prerequisite-math/linear-algebra-and-geometry.md) 有二维内积示例，随后迅速进入 attention、低秩与部署成本。[训练入门页](../files/training/beginner-model-training-primer.md) 同时覆盖一次更新、并行训练、scaling law、checkpoint 和治理。需要把第一次阅读的任务收窄，并让进阶内容具有清楚的返回入口。

### 能跟着文字理解，未必能独立做出来

结构扫描中，19 篇数学正文和 23 篇基础正文均未匹配到练习类标题、Python 代码围栏或本地示例链接。扫描匹配的是可复核的形式信号，不能据此断言页面完全没有算例。抽样页确实有公式和小例子，但缺少从输入、计算、输出到错误诊断的持续练习。

强化学习 14 篇正文均有练习类标题，其中 8 篇链接了本地示例。扩散的 [最小 DDPM 实现](../files/diffusion/minimal-ddpm-implementation.md) 已把公式、函数、shape、测试和限制连接起来，适合作为新课程的参考。该页明确说明随机张量 smoke test 只验证执行过程，不能证明模型学会了生成，这种区分应保留。

新课程每节至少提供一个完整算例、一项改变条件后的练习、可折叠的答案或判定方法。不能仅通过添加“自检与练习”标题完成改造。

### 论文精读入口被阅读工具占据

点击顶部“论文精读”进入 [本地 PDF 阅读器](../files/paper-library/index.md)。该页面隐藏侧栏导航，正文主要展示导入 PDF 和空论文库，未提供已有精读总览的入口。现有 [精读总览](../files/paper-deep-dives/index.md) 本身没有进入导航。

应让“论文精读”首先展示学习路线和已有文章，把 PDF 阅读器作为可选工具。论文按所需基础和解决的问题推荐，保留领域索引供检索。

### QA 与学习反馈承担了不同任务

[基础 QA](../files/knowledge-qa/foundations-and-transformer.md) 采用面试回答、追问展开和易错点的组织方式，适合复习口头表达。它没有让读者先独立完成计算或解释，再核对答案。课程中的练习应独立设计，QA 可继续作为查阅资料。

同页也存在值得修正的表达。关于幻觉的回答把语言模型输出概括为条件概率最高的一段文本，和前文介绍 top-k、top-p 采样的说明不一致。修订时应区分模型给出的条件分布与实际采用的解码策略。此处是站内表述的一致性问题，不能据此推断其他文章的错误比例。

### 检查器把标题一致性当成内容质量

[论文检查器](../scripts/paper_deep_dive_audit.py) 要求固定的六个三级标题、一个“阅读结论”标题及若干关键词。RDM 已有背景与问题、核心发现、总体方案、实验和训练细节，仍被判定缺少固定故事标题；其指标投机讨论也未被关键词规则识别。OpenWAM 的方法和术语内容使用不同层级的标题，同样报错。

检查应保留链接、资源、元数据、公式格式等可自动验证的项目。方法是否讲清、实验是否支持主张、引用是否对应，必须记录具体证据并人工复核。改规则时同时保留坏链接、缺元数据等负例测试，不能通过放宽所有条件让检查变绿。

## 如何使用 PaperPilot 的支持

本次已读取 PaperPilot 提示词目录的说明、完整精读、方法、系统、共享写作与综合、阶段核验，以及公式与选区解释要求。使用其中的分析标准，不需要改动 PaperPilot 代码或调用它的服务。

| 提示词来源 | 可用于网站的要求 | 应作的适配 |
| --- | --- | --- |
| `notes/modes/deep_v3.txt` | 围绕具体问题、信息流、机制与实验解释组织正文 | 专题和课程按学习任务取舍内容，避免所有页面套同一组标题 |
| `notes/modes/method_v3.txt` | 讲清输入输出、目标函数、训练与推理、更新对象、假设与实现条件 | 论文实践增加可验证的缩小实现，并区分教学简化与原论文 |
| `notes/modes/system_v3.txt` | 区分延迟、吞吐、资源、负载与测量范围 | 系统课程先教计算与测量，再进入框架和部署策略 |
| `notes/shared/system_v1.md` | 区分作者结果、第三方观察和解释，不补造证据 | 文章保留具体来源，审核状态放入维护记录 |
| `notes/stages/validate_v2.txt` | 逐项核对公式、数值、单位、引用与比较条件 | 自动检查与内容核验分开，不能把构建成功当作事实核验 |
| `interactive/formula.md` 与 `interactive/explain.md` | 解释变量、作用、训练或推理位置及上下文 | 课程公式紧跟算例，随后说明代码中的变量 |

PaperPilot 的页码引用、内部 source_ref 和 JSON 协议依赖它自己的运行环境，不应原样复制进静态网站。本站应使用真实可访问的论文链接、章节、公式编号和已有图源。数学分隔符继续遵循本站构建规则。

## 推荐方案的具体设计

### 页面组织

顶部保留四类主要入口，分别是开始学习、专题参考、论文精读、工具与查阅。

首页首先显示全栈入门路线和“从第一课开始”。已具备基础的读者可进入阶段检查，或按问题查专题。专题参考保留数学、模型、训练推理、量化算子、强化学习、生成模型、世界模型和具身智能。QA、术语表和 PDF 阅读器进入工具与查阅。探索文章与正式教学材料分别标识。

课程顺序通过页面中的明确链接表达，不依赖日期排序和自动推荐。原文章路径保留，已有链接和本地阅读数据继续可用。新交付的 Markdown 使用时间戳，工具要求固定名称的 `index.md` 保持固定名称。

### 入门课程的学习顺序

| 阶段 | 核心任务 | 完成后应能做到 |
| --- | --- | --- |
| 1 数据与数组 | 用一份小数据理解样本、特征、shape、训练与测试划分 | 检查一次输入和评测是否合理 |
| 2 一次学习更新 | 手算线性预测、损失、梯度与参数更新 | 解释 loss 为什么变化，区分参数与梯度 |
| 3 神经网络训练 | 从线性模型进入非线性、batch、过拟合与验证 | 运行小实验并定位基本训练问题 |
| 4 Attention 与生成 | 手算 Q/K/V、softmax、mask，比较采样与贪心 | 读懂一层 attention 和逐步生成过程 |
| 5 训练与推理成本 | 计算参数、激活、KV 占用并区分延迟与吞吐 | 对小任务做资源估算和受控测量 |
| 6 压缩与检索应用 | 比较量化误差，构造小型检索与回答流程 | 判断方法减少了哪种成本、引入何种误差 |
| 7 生成模型 | 从加噪、去噪进入 DDPM 训练与采样 | 对照公式运行现有最小 DDPM，并说明测试边界 |
| 8 强化学习 | 用 GridWorld 理解回报、Bellman 和策略更新 | 区分模型、采样、价值估计与控制 |
| 9 多模态与机器人 | 从观测、状态和动作进入坐标、反馈与世界模型 | 画清数据流，解释预测与执行的差别 |
| 10 论文到实现 | 从具体问题读取方法、公式、实验和代码 | 完成一份有来源、可运行、可检查的核心方法练习 |

每节主课围绕一个可完成的任务。正文按问题、例子、机制和实践的需要组织，不强制一模一样的标题。深入推导与生产系统细节链接到专题参考。运行示例说明环境、输入、预期结果和修改参数后的现象。

### 论文精读怎样接上课程

建立三条首批实践路线，分别围绕 attention 与缓存、DDPM 与采样、价值学习与世界模型。每条路线包含先修检查、代表文章、关键公式与实现对照、实验阅读任务和最小实现目标。

论文页的深度按六项核对。读者能否说明具体困难，能否画出输入到输出，能否解释目标函数及梯度作用，能否分开训练与推理，能否指出某个实验支持哪条主张，能否明确实现所需的数据与资源。对已有 DMD2 等较完整文章，补上缺少的学习连接即可。

若论文缺少某项实现信息，就在相关位置说明缺口，不能用猜测补成原文事实。示例代码只证明其覆盖的数学性质或执行行为，不能称为原论文复现。
