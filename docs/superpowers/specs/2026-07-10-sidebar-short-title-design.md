# 侧边栏短标题设计

## 文档状态

- 设计日期：2026-07-10
- 状态：用户已确认
- 适用范围：全站左侧主导航中的文章页面

## 背景与问题

现有 `hooks/paper_deep_dives_sort.py` 会读取每篇 Markdown 的一级标题，并把完整标题同步到 MkDocs 导航项。这样可以保证浏览器标题、搜索索引和文章标题一致，但也导致左侧栏出现大量过长标题，尤其在窄屏或较窄侧栏中会占用多行。

目标展示方式如下：

```text
文章正文：张量、Shape 与计算图：为什么很多模型问题先是接口问题
左侧边栏：张量、Shape 与计算图
```

## 目标

1. 文章正文继续显示 Markdown 中的完整一级标题。
2. 浏览器 `<title>` 和搜索索引继续保留完整标题。
3. 左侧主导航仅显示第一个中文冒号 `：` 之前的内容。
4. 不批量修改 Markdown 文章或 `mkdocs.yml` 中的导航名称。
5. 没有中文冒号的标题保持现状。

## 非目标

1. 不处理英文冒号 `:`。
2. 不缩短正文目录、搜索结果、浏览器标题或文章一级标题。
3. 不引入用户可配置的标题长度或分隔符列表。
4. 不复制或覆盖 MkDocs Material 的整份导航模板。

## 方案比较

### 方案 A：直接缩短 `item.title`

改动最少，但 `item.title` 同时参与浏览器标题和搜索索引生成，会把这些位置一起缩短，不满足目标。

### 方案 B：前端 JavaScript 修改侧边栏文本

可以限定 DOM 范围，但会产生首屏闪烁，无 JavaScript 时失效，并依赖主题生成的 CSS 选择器。

### 方案 C：设置 Material 导航专用标题

保留完整 `item.title`，仅为含中文冒号的页面设置 `item.typeset.title`。Material 9.7.6 的左侧导航模板优先显示 `typeset.title`，而浏览器标题、搜索索引和正文仍使用完整标题。

采用方案 C。它只需修改现有 hook，无需模板覆盖或客户端脚本。

## 详细设计

### 标题规则

新增一个单一职责的标题转换函数，规则如下：

1. 使用第一个中文冒号 `：` 分隔标题。
2. 对冒号前的内容执行首尾空白清理。
3. 前缀非空时返回前缀作为侧边栏标题。
4. 标题不含中文冒号，或清理后的前缀为空时，不设置短标题并继续显示完整标题。
5. 多个中文冒号只在第一次出现的位置拆分。

示例：

| 完整标题 | 侧边栏标题 |
| --- | --- |
| `张量、Shape 与计算图：为什么很多模型问题先是接口问题` | `张量、Shape 与计算图` |
| `标题：副标题：补充说明` | `标题` |
| `English: subtitle` | `English: subtitle` |
| `没有副标题` | `没有副标题` |
| `：缺少主标题` | `：缺少主标题` |

### 数据流

```text
Markdown H1
  -> 现有 hook 读取完整标题
  -> item.title = 完整标题
  -> 若存在有效中文冒号前缀，则 item.typeset.title = 短标题
  -> Material 左侧导航显示短标题

完整 item.title
  -> 浏览器标题
  -> 搜索索引

Markdown H1
  -> 文章正文完整标题
```

### 影响文件

- `hooks/paper_deep_dives_sort.py`：生成并设置导航专用短标题。
- `tests/test_paper_deep_dives_sort.py`：覆盖标题拆分和递归导航同步行为。

不修改文章 Markdown，不修改现有导航结构。

## 兼容性与风险

`typeset` 是 MkDocs Material 的主题专用导航字段，不是 MkDocs 的通用接口。当前仓库使用 Material 9.7.6，其导航模板明确优先读取 `nav_item.typeset.title`。未来升级主题时，构建级测试必须确认该行为仍然成立。

短标题只设置在具有源文件路径的叶子页面上。分组标题和没有中文冒号的页面不额外写入 `typeset`，避免改变无关导航行为。

## 测试与验收

按测试先行方式完成以下验证：

1. 中文冒号标题取第一个冒号前缀。
2. 多个中文冒号只拆分一次。
3. 无中文冒号和英文冒号标题保持完整。
4. 空前缀回退到完整标题。
5. 导航同步后 `item.title` 仍为完整标题，`item.typeset.title` 为短标题。
6. 递归嵌套页面同样生效。
7. 构建产物中：
   - 左侧主导航只出现短标题；
   - 正文 `<h1>` 保留完整标题；
   - 浏览器 `<title>` 保留完整标题；
   - `search/search_index.json` 保留完整标题。
8. 运行相关单元测试和一次完整 MkDocs 构建。
